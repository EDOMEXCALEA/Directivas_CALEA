# 📄 Directivas CALEA - Estado de México

Sistema web para la consulta y descarga de documentos normativos y directrices CALEA del Estado de México.  
Desarrollado como una **Progressive Web App (PWA)** alojada en GitHub Pages, accesible desde cualquier dispositivo y con capacidad de instalación en Android e iOS.

## 🚀 Acceso a la aplicación

---

## 📌 Descripción del proyecto

Este repositorio contiene una **webapp** que permite:

- Consultar y descargar documentos PDF organizados por capítulo.
- Navegar por secciones desplegables (acordeón) con nombre de capítulo personalizado.
- Buscar documentos por nombre o por número de capítulo.
- Instalar la aplicación en dispositivos móviles para uso sin conexión (PWA).
- Visualizar y descargar documentos desde cualquier navegador moderno.

Los documentos se agrupan automáticamente según el número de capítulo extraído del nombre del archivo (formato `numero_nombre.pdf` o `capitulo_XX_nombre.pdf`). Los archivos sin número de capítulo se agrupan en la sección **"Otros Documentos"**.
